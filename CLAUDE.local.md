## Engineering Principles

### Core Implementation Guidelines
- Spec-Driven Implementation: Strictly follow given specifications
- Always seek clarification for unclear or incomplete specs
- Update documentation to reflect requirements and reasoning
- Check existing codebase before creating new functions/utilities
- Avoid redundant implementations
- Propose multiple options for major changes before implementation

### Interaction Conventions
- Use ❓Question to raise uncertainties
- Use 📄Update to explain documentation changes
- Use 💡Proposal to present decision options
